## 1. الملخص التنفيذي

نظام **Grocery Store Management & POS System** هو تطبيق لإدارة عمليات متجر البقالة ونقطة البيع، صُمم لتجميع عمليات البيع وإدارة المنتجات والمخزون والعملاء والفواتير والمدفوعات والتقارير في نظام واحد.

يعتمد النظام على تطبيق Flutter مع قاعدة بيانات SQLite محلية، ويهدف إلى توفير دورة عمل واضحة تبدأ من تسجيل المنتجات والمخزون، مروراً بعملية البيع والمسح بالباركود، وانتهاءً بحفظ الفاتورة وتحديث المخزون وإظهار المعلومات المالية والتقارير.

كما تم تصميم النظام ليكون قابلاً للتوسع مستقبلاً لإضافة إدارة الديون، سجل الدفعات، التنبيهات للعملاء، وإرسال إشعارات البريد الإلكتروني.

---

## 2. أهداف النظام

يهدف النظام إلى:

- تسريع عملية البيع داخل المتجر.
- تقليل الإدخال اليدوي للمنتجات.
- استخدام الباركود لتحديد المنتجات بسرعة.
- إدارة المخزون والكميات المتوفرة.
- حفظ بيانات العملاء.
- دعم المبيعات النقدية والآجلة والجزئية.
- تتبع المبالغ المدفوعة والمتبقية.
- إنشاء الفواتير وحفظ تفاصيلها.
- توفير تقارير مبيعات وأرباح.
- اكتشاف المبالغ غير المحصلة.
- توفير أساس محاسبي مبسط يمكن تطويره لاحقاً.
- الحفاظ على سلامة البيانات باستخدام معاملات SQLite.
